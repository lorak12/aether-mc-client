## Priority Issues

[P0] Launch failure and crash recovery leave nothing actionable. Pre-start failures reset to idle with a ~4 s toast (app/store.tsx); crashes show a raw log tail with no cause or retry (pages/home/Home.tsx:131-159). Fix: persistent inline error card with Retry; crash card with a plain reason, Launch again, log behind a disclosure. Command: harden, then clarify.

[P1] Developer-facing copy in player UI: config-file and env instructions in RightSidebar.tsx:60, Store.tsx:57, Content, install, Settings. Fix: player copy with one action; config instructions behind About/Support. Command: clarify.

[P1] Shareable-profile promise has no UI: only .mrpack export and modpack import. Fix: Export/Import/Share profile entries. Command: shape, then onboard.

[P2] "Vanilla" names both the profile kind and the built-in-mods loader. Fix: rename the loader to "Built-in mods only". Command: clarify.

[P2] First run does not route to sign-in; "Welcome back" for new players (Home.tsx:44); disabled Launch reason only in a tooltip. Fix: two-step first-run card, visible disabled reason. Command: onboard.

Also: reduced-motion rule at styles.css:238 zeroes all transitions; error toasts are aria-live polite (shell/Toasts.tsx:7); generic shell (bolder); duplicate entry points (distill).
