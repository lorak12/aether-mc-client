# 10 — HUD and information mods

## What
Extend FPS (min/max/avg/1%/0.1% low, graph, color), Ping (avg/min/max/graph/thresholds), CPS (middle, windows, graph), Keystrokes
(shift/ctrl/MMB, CPS in buttons), Armor Status (held/offhand, bars, horizontal), Potions (sort, hide negative, compact),
Coordinates (chunk, facing, light, rotation), Direction (compass strip), Clock (MC time, date, seconds), Memory (percent, graph).
New: Boss Bar, Titles, Scoreboard, Saturation/Food, Playtime, Statistics, Network Monitor, Debug HUD, Hotbar info, Item Durability,
Height Limit, Biome/Structure info, WAILA extension, Rendering diagnostics, Health display, Damage indicator, TNT Timer,
Hardcore / PvP / Survival / BedWars / SkyBlock dashboards, Achievement tracker, Server status.

## Acceptance
Unit tests for logic; in-game autotest screenshots show them.
